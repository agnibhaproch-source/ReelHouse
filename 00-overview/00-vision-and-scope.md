# 00 — Vision & Scope

## One-line pitch
A movie discovery site that feels like walking into a cinema: the lights dim, the projector hums, and every interaction responds like film.

## What it is
- Browse trending, popular, top-rated, upcoming, by genre, by language (Hindi, Tamil, Telugu, Malayalam, Korean, Japanese, English, etc. — "universal")
- Rich movie detail pages: backdrop, logo, cast, trailer, similar titles, reviews
- Search with instant results
- Accounts, multiple profiles, watchlist, ratings
- Trailer playback in a cinematic player

## What it is NOT
- Not a streaming/piracy site. No full movies. Trailers only (YouTube via TMDB).
- Not a Netflix clone in branding. Own name, own identity, own palette.

## Experience pillars
1. **Cinematic** — film grain, projector light, letterboxing, depth.
2. **Alive** — every hover, scroll, click, and route change has motion.
3. **Reactive** — motion responds to cursor position, scroll velocity, and intent.
4. **Fast** — 60fps. Motion that drops frames gets removed.
5. **Accessible** — full reduced-motion mode, keyboard-navigable, screen-reader friendly.

## Success criteria
- Lighthouse Performance ≥ 90 desktop, ≥ 80 mobile
- No animation below 55fps on a MacBook Air (Chrome performance panel)
- Every interactive element defines idle, hover, active, focus, disabled states
- Portfolio-ready: a 60-second screen recording that makes people ask "how did you build this?"
